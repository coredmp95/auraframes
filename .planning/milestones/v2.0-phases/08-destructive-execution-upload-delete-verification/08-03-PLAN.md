<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| CLI stdin (TTY) → confirmation gate | Interactive y/N input authorizes an irreversible action |
| --frame substring resolution → destructive target | A substring match could land on an unintended frame |
| non-interactive invocation → --apply | A cron/CI run must never silently proceed on an unanswerable prompt |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-08-08 | Tampering | --frame substring resolution before an irreversible apply | high | mitigate | Task 1 echoes the resolved frame's name+id in the confirmation prompt (D-04) on top of Phase 6's ambiguous/not-found guards |
| T-08-09 | Elevation of Privilege | non-interactive --apply without --yes | high | mitigate | Task 1 fails closed via sys.stdin.isatty() — prints an error and exits non-zero, never hangs or silently proceeds (D-03) |
| T-08-10 | Denial of Service / Tampering | mass-delete from a misconfigured/empty local dir (no --max-delete this phase) | medium | accept | SYNC-05 circuit breaker is deferred to v2; residual risk mitigated by the full untruncated plan listing shown before the single y/N gate (Phase 7 D-07) — document as accepted risk in 08-SECURITY.md |
| T-08-11 | Repudiation | partial-failure batch | high | mitigate | Task 1 prints the D-10 separated summary and returns non-zero on any failure (SYNC-04) so the user is never unaware a write failed |
| T-08-SC | Tampering | pip/uv installs | low | accept | No package installs this phase (RESEARCH.md audit table empty) |
</threat_model>
