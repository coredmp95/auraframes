## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| user CLI arg -> resolve_frame | `--frame <value>` is untrusted free-form input; used only for in-memory string comparison against Frame.name / Frame.id |
| CLI -> Aura/pushd API | authenticated GET responses (get_frames/get_frame/get_assets) cross into the process; undocumented, drift-prone API |
| process -> stdout/stderr | rendered metadata, photo lines, and error messages leave the trust boundary to the terminal |
