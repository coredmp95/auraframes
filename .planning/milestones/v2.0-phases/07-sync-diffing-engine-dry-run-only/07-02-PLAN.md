<objective>
Wire the dry-run sync engine into the CLI: add a `sync <dir> --frame <name|id>`
subcommand whose `run_sync()` handler resolves the target frame, scans the local
directory, computes the plan via the Plan-01 engine, and prints a full,
untruncated upload/delete/unchanged report — then exits, executing nothing.

Purpose: This is the user-facing SYNC-01 deliverable. It reuses Phase 6's frame
resolution and asset pagination verbatim and adds only the new command surface
and the plan output formatting. There is deliberately no `--apply`/`--yes` flag
in this phase — the destructive path is Phase 8.

Output: `sync` subparser + `run_sync()` in `auraframes/cli.py`, a `main()`
dispatch branch, and offline CLI tests in `tests/test_cli_sync.py`.
</objective>

## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| user → CLI | User supplies `dir` (a local path, scanned recursively) and `--frame` (resolved against account frames). |
| network → app | Frame list + assets fetched via the already-live-verified read path (get_frames / get_all_assets); consumed read-only. |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-07-04 | Elevation / Tampering (write path) | run_sync command surface | high | mitigate | No `--apply`/`--yes` flag exists and run_sync calls only scan_directory/compute_plan/print — there is no code path from this command to any mutating primitive. The dry-run guarantee is structural, not a runtime flag check. Phase 8 owns the destructive surface. |
| T-07-05 | Information Disclosure | plan output | low | mitigate | Delete candidates print id + taken_at only (D-08), never the meaningless UUID filename or hash; credentials are never echoed (existing status/inspect convention). |
| T-07-06 | Denial of Service | scan on a huge/mistyped directory | low | accept | Dry-run only prints a plan; nothing is executed, so a mis-pointed directory produces a reviewable (possibly large) plan, not an irreversible action. The mass-delete circuit-breaker (SYNC-05) is deferred to v2 and out of this phase's scope. |
| T-07-SC | Tampering | pip/uv installs | low | accept | No new packages — only stdlib `pathlib` and the Plan-01 engine are imported. No install task. |
