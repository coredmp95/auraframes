<objective>
Account for the 58 stuck placeholder rows on the live frame: identify them with a predicate
narrow enough that being wrong is unlikely, report the count from two places that cannot
disagree, and expose a removal path that is reachable only when the operator names it.

Purpose: `select_asset` calls whose upload never completed left rows with no `uploaded_at`,
no `file_name` and no `md5_hash`. `delete_asset` returns 200 and removes nothing; `remove_asset`
returns 404. The rows are invisible to the diff engine, they appear to be the cause of the
171-vs-149 count mismatch, and today the operator has no way to even see how many there are.
This is data hygiene on existing bad state — deliberately outside the sync loop.

Output: a new `auraframes/reconcile.py` with a pure predicate and a separate mutating function,
a `reconcile` CLI verb, a one-line count in `inspect`, and offline tests covering the predicate,
the age guard and both CLI paths.
</objective>
