<objective>
Widen the upload path to the file types a Google album actually contains, and decide the type
from the bytes rather than the filename.

Purpose: `_prep_upload` raises closed on both `.png` and `.heic` today — the map at
`auraframes/sync.py:64` covers only `.jpg`/`.jpeg` — while `ELIGIBLE_EXTENSIONS` already declares
all four. Google albums routinely contain PNG and HEIC, which makes this a hard blocker for
Phase 14, not debt. Deriving the UTI from `image.format` also removes the filename as a trust
anchor: a `.jpg` that is really a PNG can no longer be mislabeled server-side.

Output: `pillow-heif` as a declared dependency, an explicit content-derived UTI table that still
fails closed, and offline tests covering every supported format plus the mislabeled, unmapped and
undecodable cases.
</objective>
