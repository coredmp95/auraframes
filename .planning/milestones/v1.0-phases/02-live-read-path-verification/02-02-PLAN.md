## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| client → Aura API (`/frames/{id}/assets.json`) | Untrusted paginated responses; a drifted/failed page must not be processed as success |
| imgproxy (`imgproxy.pushd.com`) → process | Unauthenticated image bytes flow into `piexif.insert`; a non-JPEG/corrupt body must fail loudly, not save a 0-byte file |
| process → Nominatim/OSM (third party) | Outbound geocoding of `location_name`; UA must comply with ToS; failures must be tolerated |
