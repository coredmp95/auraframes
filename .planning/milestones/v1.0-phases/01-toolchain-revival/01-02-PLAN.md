<objective>
Migrate the pydantic model layer from v1 to v2 so the entire `auraframes` package imports
cleanly under pydantic 2.x, preserving the `AllOptional` partial-model behaviour, and add a
committed pytest smoke test.

Purpose: ENV-03. Three import-time v1 breakers must be replaced (the
`pydantic.main.ModelMetaclass` in `meta.py`, the `pydantic.json` import in `utils/io.py`,
and the `@validator` in `asset.py`), plus the `FramePartial` consumer in `frame.py`. The
smoke test (D-08) makes import-cleanliness and partial-optionality continuously verifiable
for Phases 2-3.
Output: rewritten `meta.py` + `io.py`, migrated `frame.py` + `asset.py`, new
`tests/test_imports.py`.

OPEN QUESTIONS RESOLVED IN THIS PLAN:
- Q#1 (base-model `Optional[...]` defaults): FIX NOW. Add `= None` to the ~14 `Optional`
  fields in `Frame` and ~30 in `Asset` (Task 2). This is NOT a D-05 violation — D-05 locks
  the runtime `.dict()` CALL SITES in `api/*` (untouched here), not field declarations.
  Adding `= None` faithfully restores pydantic v1's implicit-None semantics, which is exactly
  ENV-03's "preserving the model layer behaviour," is confined to the two model files already
  being edited, and prevents a guaranteed Phase 2 instantiation failure (RESEARCH Pitfall 1 /
  Open Q#1 recommendation).
- Q#2 (AssetPartialId validator): FAITHFUL STRAIGHT-PORT to `@field_validator`. Preserve the
  pre-existing latent field-ordering no-op (RESEARCH Pattern 3 behavior note). The
  `model_validator(mode="after")` correctness fix is a Phase-2 candidate, NOT done here.
- Q#3 (dev deps): resolved in plan 01-01 (`[project.optional-dependencies]` dev group).
</objective>
