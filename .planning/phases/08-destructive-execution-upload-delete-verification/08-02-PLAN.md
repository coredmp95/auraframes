<objective>
Add `execute_plan()` — the first and only mutating counterpart to Phase 7's pure `compute_plan()` — to `auraframes/sync.py`. It performs the real upload round-trip for each new local file and the real `remove_asset` disassociation for each gone-locally frame asset, with a per-item continue-past-failure model and a separated success/failure result (SYNC-03, D-08/D-09/D-10). It executes nothing destructive beyond `remove_asset`: the hard-delete primitive has no code path here (D-06).

Purpose: Concentrate every new mutating call in one structurally-isolated, offline-testable function, preserving the "structural, not `if apply:`-flag" dry-run/execute boundary the project committed to.
Output: `execute_plan(plan, aura, frame_id, *, s3_client, sqs_client) -> ExecutionResult`; `ExecutionResult` dataclass; offline tests with injected S3/SQS fakes.
</objective>
