  <action>
Create `probes/cookie_vault.py`:
1. `DEFAULT_VAULT_PATH = Path("~/.config/auraframes/probes/google-cookies.json")` (expanded; untracked — never inside the repo).
2. `save(cookies: list[dict])` — writes JSON atomically with `os.open(..., os.O_WRONLY|os.O_CREAT|os.O_TRUNC, 0o600)`; refuses to write if the resolved path is inside the git repo (raise `CookieVaultError` naming the path).
3. `load()` — reads the vault; raises `CookieVaultError("no session — run the bootstrap first")` if absent.
4. **Structural denylist (D-06):** a module-level `_DENYLIST_PREFIXES = ("auraframes.sync", "auraframes.reconcile", "auraframes.cli")` and `assert_not_sync_path(caller_module_name)` — if the caller's module name starts with any denylist prefix, raise `CookieVaultError` naming the importing module. Enforce it inside `load()` via `sys._getframe(1).f_globals.get("__name__", "")` so a sync-path import literally cannot read cookies.
5. `cookies_for_httpx()` — returns an `httpx.Cookies`-shaped dict from the vault records.

Add vault path + `probes/.probe-downloads/` to `probes/.gitignore`; verify with `git check-ignore` that neither can be committed.

Create `tests/test_probe_browser.py` covering: save→load round-trip preserves cookie names/values; file mode is 0600 after save; load from a repo-inside path raises `CookieVaultError`; a caller module named `auraframes.sync` (simulated via monkeypatching the frame inspection) is refused with the module named in the message; no test imports playwright.
  </action>
