<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| env/CLI → process | Untrusted-shaped config (`AURA_WRITE_BUDGET_*` floats, `AURA_WRITE_BUDGET_WAIT`/`AURA_GEO_FAIL_OPEN` booleans, `AURA_STATE_DIR`, `AURA_COUNTRY`, `--max-wait` etc.) is parsed into control values |
| process → local filesystem | Per-account budget state JSON path is derived from `sha1(AURA_EMAIL)[:12]` and written under `AURA_STATE_DIR` |
| client → ipinfo.io | Default geo resolver egress (constructed in `_build_geo_check`; behavior owned by 09-01) |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-09-03 | Denial of Service (to the user's own workflow) | `settings.py` env parsing / `push` flag parsing | medium | mitigate | Parse floats via bare `float(os.getenv(...))` and booleans via `_bool_env` at settings-load (import) time so a malformed value fails fast and loud (clear `ValueError`) rather than as a confusing mid-run traceback deep inside `WriteBudget.acquire`; argparse `type=float` validates `--max-wait` at parse time. A bad value must never silently disable protection. |
| T-09-02 | Information Disclosure | `_build_write_budget` state-file path + `WriteBudget.save` body | low | mitigate | Only `sha1(email)[:12]` (non-cryptographic filename-uniqueness hash — not a security boundary) appears in the filename; the JSON body carries only `tokens` + `updated_at`. Negative-assertion test confirms no email/credential is ever serialized. |
| T-09-01 | Spoofing / Information Disclosure | default geo resolver (ipinfo.io) via `_build_geo_check` | low | mitigate | `fail_open=AURA_GEO_FAIL_OPEN` (default true) so an ipinfo outage degrades to "geo skipped, write proceeds" rather than blocking; resolver injectable. A hijacked resolver returning a matching country only disables a guard, never enables a new write attack. |
| T-09-SC | Tampering | pip/uv installs | low | accept | No new packages this phase (stdlib + existing `httpx`, per RESEARCH.md Package Legitimacy Audit) — nothing to install. |

(ASVS Level 1, block-on high. Highest severity here is medium → nothing blocks execution.)
